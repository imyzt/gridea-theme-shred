# gridea-theme-shred

作者：[imyzt](https://github.com/imyzt)

面向 [Gridea Pro](https://gridea.dev/) 的**文字博客**主题。独立插件目录，不修改其他主题源码。

## 设计取向

借鉴优秀个人站常见的排版层次、留白与克制细节，但信息架构按「只有博客」来做：

- 首页 = 站点身份 + 阅读流（首篇加重，其余按时间列表）
- 不做作品集分区、项目卡、口号条、章节轨
- 「碎纸」只作为小装饰（标题旁碎边），不是整站隐喻

## 安装

```bash
ln -sfn ~/dev/openSource/gridea-theme-shred /path/to/Gridea/themes/shred-theme
```

Gridea Pro 选择主题 **shred**，预览 / 重新生成。
